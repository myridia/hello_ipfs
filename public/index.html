hello ipfs

one file · no requests

This whole page is a single index.html. The stylesheet, the bee and the script are inline, so the page asks the network for exactly one thing: itself. Add it to IPFS and the address of those bytes is the content identifier — change one character and the address changes.

cid reading…
origin -
served by -
external requests - 
# add it (writes nothing but the hash)
ipfs add -r --only-hash public

# put a name on it
ipfs name publish /ipfs/<cid>

# read it back, no gateway DNS needed
ipfs gateway
Ask for this path over ipfs.io and the cid above is read back from the URL.
